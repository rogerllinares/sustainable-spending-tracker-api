## F1 resolution — *not a bug, cold-start UX gap*

**Original symptom (sesión anterior):** dashboard stuck on "Loading…" after login.

**Root cause (sesión 2026-05-12 segunda repro):** Render free tier puts the backend to sleep after ~15 min of inactivity. First request triggers a wake-up that took **183 seconds** in our repro. The Bearer `demo-*` token is sent correctly, CORS works (`access-control-allow-origin: https://sst-frontend-steel.vercel.app`), the request fires and returns `200 OK` with valid JSON once the backend wakes. **No code bug.**

**Previous hypothesis (AuthContext / localStorage / interceptor) was wrong.** The auth flow is in-memory only by design and works correctly with React Router's `navigate()` (no hard reload). No localStorage persistence needed for a single-session demo.

### UX gap (real, fixed)

Skeletons in `HeroSection`, `TrendChart`, `TransactionsTable` were silent during the 50-180s cold-start. To a recruiter that looks like a broken site. **Fixed** by adding inline cold-start hint text to all three loading branches (the existing error branches already had it, but error path isn't reached when the request is just slow).
